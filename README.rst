=====================
wflow NbS design tool
=====================


Plugin description
==================

Plugin for QGIS to easily schematize and calculate the effect of NbS using a wflow model 


The wflow NbS design tool includes some basic `wflow functionalities <wflow_functionalities.html>`_: 

- `Load layers <wflow_functionalities.html#load-layers>`_   
  
- `Run calculation <wflow_functionalities.html#run-calculation>`_

- `Add gauge locations <wflow_functionalities.html#add-gauge-locations>`_

- `Results viewer <wflow_functionalities.html#results-viewer>`_


And the wflow NbS design tool includes some `specific functionalities for NbS <NbS_schematization.html>`_: 

- `Add reservoirs <NbS_schematization.html#add-reservoirs>`_
  
- `Change landuse <NbS_schematization.html#change-landuse>`_

- `Add check dams <NbS_schematization.html#add-check-dams>`_

- `Add terracing <NbS_schematization.html#add-terracing>`_


Note that a basis wflow model is required to use the wflow NbS design tool.
How to build a wflow model is described in the wflow documentation: https://deltares.github.io/Wflow.jl/stable/. 
The wflow NbS design tool makes extensively use of the HydroMT_wflow package: https://deltares.github.io/hydromt_wflow/stable/.
