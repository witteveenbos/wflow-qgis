=====================
wflow NbS design tool
=====================

    Plugin for QGIS to easily schematize and calculate the effect of NbS using a wflow model 


The wflow NbS design tool includes some basic wflow functionalities: 

- Load layers
  
- Run calculation

- Add gauge locations

- Results viewer


And the wflow NbS design tool includes some specific functionalities for NbS: 

- Add reservoirs
  
- Change landuse

- Add check dams

- Add terracing
