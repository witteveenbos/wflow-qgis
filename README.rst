=====================
wflow NbS design tool
=====================


Plugin description
=======

Plugin for QGIS to easily schematize and calculate the effect of NbS using a wflow model 


The wflow NbS design tool includes some basic wflow functionalities: 

- Load layers
  
- Run calculation

- Add gauge locations

- Results viewer


And the wflow NbS design tool includes some specific functionalities for NbS: 

- Add reservoirs
  
- Change landuse

- Add check dams

- Add terracing


Note that a basis wflow model is required to use the wflow NbS design tool.
How to build a wflow model is described in the wflow documentation: https://deltares.github.io/Wflow.jl/dev/
